# data ディレクトリ

在庫表（`inventory.html`）が読み込む、ミザルの**採用品一覧設定CSV**を置くための場所です。

## 使い方

このディレクトリに `MedAdoptlist.csv` という名前で置いておくと、
在庫表を開いたときに自動で読み込まれます（初回のみ。以降はブラウザに保存されたデータを使用）。

ファイルを置かない場合は、在庫表の画面上で「CSV読込」ボタン、
またはドラッグ＆ドロップで読み込んでください。

## 注意

**CSVファイルはGitの管理対象外です（`.gitignore`で除外）。**

採用品一覧CSVには在庫数や帳合価格（仕入価格）といった薬局の内部情報が含まれます。
このリポジトリは公開設定のため、CSVそのものをコミットしないでください。
