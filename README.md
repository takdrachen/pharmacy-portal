# 緑ヶ丘調剤薬局 情報共有ポータル

薬局スタッフ向けの情報共有・業務管理ポータルサイトです。

## 機能

- **ダッシュボード**: シフト・お知らせ・薬剤情報の概要表示、カスタマイズ対応
- **お知らせ掲示板**: 業務連絡・研修情報の投稿・管理
- **シフト管理**: カレンダー形式でのシフト表示・編集
- **薬剤情報管理**: 薬剤データベースの検索・登録・編集（テーブル/カード表示切替、高度なフィルタリング対応）
- **従業員管理**: スタッフ情報の管理
- **AIアシスタント**: Google Gemini APIを活用した薬局業務支援チャット
- **在庫表（ミザル停止時間帯用）**: ミザルの採用品一覧CSVを読み込み、検索・絞り込みできるオフライン在庫参照ページ

## 技術スタック

- HTML5 / CSS3 / JavaScript (Vanilla)
- Font Awesome 6.4
- Google Fonts (Noto Sans JP)
- localStorage によるデータ永続化

## 使い方

GitHub Pagesで公開されています。ブラウザからアクセスするだけで利用可能です。
データはブラウザのlocalStorageに保存されます。

## 在庫表（ミザル停止時間帯用）

`inventory.html` は、ミザルが使えない時間帯に在庫を確認するための単独ページです。
ポータル上部のナビゲーション「在庫表」から開けます。

デザインは疑義照会管理システム（cruisergigi）に合わせており、
サイドバー＋絞り込みパネル＋一覧の3ペイン構成です。
アイコンはインラインSVGのため、外部CDNが読めない環境でも表示が崩れません。

### 使い方

1. ミザルで **採用品一覧設定CSV**（`MedAdoptlist.csv`）を出力する
2. 在庫表を開き、「CSV読込」ボタンまたはドラッグ＆ドロップで読み込む
3. 次回以降は自動で表示される（データはブラウザのlocalStorageに保存）

`data/MedAdoptlist.csv` にファイルを置いておくと、初回に自動で読み込まれます。

### できること

- **検索**: 商品名・薬品名・一般名・メーカー・規格・棚番・YJコード・レセプト電算コード・JAN/GTINコードを横断検索
  - 全角/半角、ひらがな/カタカナの違いを吸収（例:「ﾑｺﾀﾞｲﾝ」「ムコダイン500」でもヒット）
  - スペース区切りでAND検索。`/` キーで検索欄にフォーカス
- **絞り込み**: 使用区分（内服/外用/注射/材料）、在庫状況、後発区分、棚、帳合先、メーカー、属性（劇・毒・向Ⅱ・向Ⅲ・習・処方・日局）、注意フラグ（管理品・経過措置・販売中止・第３棚名称の記載・供給確保）
- **並べ替え**: 商品名 / 棚番 / 在庫数 / 採用日 / 単位薬価
- **表示切替**: 一覧（テーブル）/ カード / 棚別グループ（サイドバーで切替）
- **折りたたみ**: サイドバー・絞り込みパネルはそれぞれ折りたたみ可能（状態はブラウザに保存）
- **集計**: 表示中の件数・在庫0件数・残りわずか件数・在庫金額（薬価ベース）
- **出力**: 表示中の内容をCSV出力（Excel対応のUTF-8 BOM付き）、印刷
- 品目をクリックすると全項目の詳細を表示

### デスクトップ用の単一ファイル版

ポータルを経由せず、パソコンのデスクトップに置いて使う版をビルドできます。
HTML・CSS・JavaScript・ロゴ・CSVデータを1つのHTMLにまとめるため、
**ダブルクリックするだけで開き、インターネット接続も不要**です。

```
node tools/build-standalone.js <CSVファイル> [出力先]
例: node tools/build-standalone.js ~/MedAdoptlist.csv dist/在庫表.html
```

- 収録したデータが最初から表示されるため、読み込み操作は不要です
- 単一ファイル版でも「CSV読込」で最新のCSVに差し替えられます（ブラウザに保存）
- 差し替えたあとは、サイドバーの「元のデータに戻す」で収録データに戻せます
- 外部への通信は一切ありません（フォントも端末のものを使用）

**ビルドした単一ファイルはGitの管理対象外です**（`dist/` を `.gitignore` で除外）。
在庫数や帳合価格を含むため、リポジトリにコミットしないでください。

### 注意事項

- 表示される在庫数は **CSVを出力した時点のもの** です。出力後の入出庫は反映されません。
  正式な在庫はミザルで確認してください。
- 取り込みから7日経過すると、再出力を促す警告が表示されます。
- **CSVファイルはGitの管理対象外です**（`.gitignore`で除外）。
  在庫数や帳合価格など薬局の内部情報を含むため、リポジトリにはコミットしないでください。
